# Guía de Recursos 3D para Personajes de Curileta

Coloca en esta carpeta (`apps/web/public/images/characters/`) los renders o diseños 3D de cada personaje.

## Nombres de Archivo Exactos (Recomendado: PNG con fondo transparente o WebP)

| Personaje | Archivo | Rol / Descripción |
|---|---|---|
| **Curileta** | `curileta.png` | Lagartija exploradora con mochila, sombrero y lentes |
| **Pompón** | `pompon.png` | Conejito blanco guardián del bosque y de las cartas |
| **Quetzal** | `quetzal.png` | Ave de plumas verdes esmeralda sagrada de México |
| **Lulú** | `lulu.png` | Llama andina lanuda de Machu Picchu (Perú) |
| **Emi** | `emi.png` | Escarabajo pelotero sabio de las pirámides (Egipto) |
| **Picu** | `picu.png` | Frailecillo ártico con pico de colores (Islandia) |
| **Zipi-Bot** | `zipi-bot.png` | Robot de juguete musical de Tokio (Japón) |
| **Joey Canguro** | `joey-canguro.png` | Mamá Canguro y el bebé Joey con su koala de trapo (Australia) |
| **Kiki** | `kiki.png` | Pájaro kiwi nocturno y redondo de Waitomo (Nueva Zelanda) |
| **Bao** | `bao.png` | Oso panda gigante comiendo bambú en la Gran Muralla (China) |
| **Gino** | `gino.png` | Ratoncito chef con gorro blanco de Florencia (Italia) |
| **Lola** | `lola.png` | Tortuga mora sabia de Andalucía y el Bosque Encantado (España) |

## Especificaciones Técnicas Recomendadas:
- **Formato:** `.png` (con fondo transparente) o `.webp`.
- **Resolución:** `1024 x 1024 px` (mínimo `512 x 512 px`).
- **Encuadre:** Plano de cuerpo entero o medio cuerpo centrado con iluminación cálida/aventura.
- **Peso:** Optimizado (menos de 500 KB por imagen para carga ultra rápida).

El sistema web detecta automáticamente si colocas estos archivos y los renderiza con efecto 3D tilt interactivo.
